# Wokwi Emulator (VS Code)

## Setup

1. Install the Wokwi VS Code extension.
2. Build firmware + filesystem and generate the Wokwi image:

```
pio run -e esp32_usb -t wokwi
```

3. In VS Code, run **Wokwi: Start Simulator**.

Wokwi loads the configuration from `wokwi.toml` and `diagram.json` in the repo root,
and uses `.pio/build/esp32_usb/firmware_merged.bin` (generated by the script above),
which bundles the bootloader, boot_app0, partitions, firmware, and LittleFS image.

When using Wokwi WiFi, the CleverCoffee web UI is available at
`http://localhost:8180` (see the port forward in `wokwi.toml`).

## WiFi config (skip portal)

To skip the WiFi portal in Wokwi, set `system.wifi.ssid` and
`system.wifi.password` in `/data/config.json` (LittleFS). Example:

```json
{
  "system": {
    "wifi": {
      "ssid": "Wokwi-GUEST",
      "password": ""
    }
  }
}
```

There is also a ready-to-use example config at `docs/example_config.json` with
values adjusted to match `diagram.json`.
